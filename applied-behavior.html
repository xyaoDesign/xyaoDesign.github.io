Project Overview

This project explores how Augmented Reality (AR) can support Applied Behavior Analysis (ABA) therapy for children with autism, creating an interactive, clinician-guided learning experience that complements traditional therapy methods.

The application uses QR-coded physical cards to display interactive 3D learning stimuli on a tablet, starting with color identification. By combining structured feedback, automated data collection, and customizable learning assets, the system aims to make therapy sessions more engaging while reducing the preparation and material demands on clinicians.

The project also incorporates eye-tracking technology to explore how children visually respond to different learning stimuli, providing insights for future instructional design.

The Design Challenge

Creating an effective learning tool requires more than delivering interactive content. The experience must also be intuitive and efficient for the people preparing and managing therapy sessions.

The existing six-screen onboarding process introduced unnecessary complexity during setup, while limitations in asset organization made managing learning content less flexible.

The design challenge was to simplify user interactions, reduce unnecessary steps, and make essential functions easier to access, allowing users to focus more on the learning experience and less on navigating the technology.

My Role & Design Approach

As the Technical Artist and Developer, I contributed to both the user experience and technical implementation, focusing on simplifying workflows, improving usability, and resolving development challenges.

Onboarding & User Flow Redesign

Redesigned the six-screen onboarding flow into three guided screens, reducing the number of setup screens by 50%. The redesign simplified navigation and streamlined the preparation experience, helping users move through setup with fewer steps.

Asset Library & User Customization

Designed and developed an interactive asset-library feature that allows users to customize and organize learning assets. The feature improves content accessibility and gives users greater flexibility in managing materials within the application.

Technical Problem-Solving & Implementation

Resolved a persistent 3D asset-rendering issue that had blocked production for approximately three months, identifying and fixing the problem within my first two weeks.

Independently developed and integrated front-end and back-end features, helping accelerate project delivery by approximately two months while supporting a more reliable and consistent application experience.

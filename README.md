# Xinyu Jane Yao — Portfolio

Static portfolio site (plain HTML, CSS and a little JavaScript — no build step).

- `index.html` — landing page (work + about)
- `bwc.html`, `applied-behavior.html`, `machine.html`, `obstetrics.html`, `temple.html`, `eye.html` — project pages
- `site.css`, `site.js` — shared styles and behaviour (filters, lightbox, before/after sliders)
- `assets/` — images, videos and the BWC research PDF

Hosted with GitHub Pages.
